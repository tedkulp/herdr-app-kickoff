### Added

- Open a local folder as a new herdr-app space with an installed agent or the default shell.
- Choose folders with a native picker and remember the last agent selection.

- Filter zoxide directory history and local branches with the keyboard.
- Switch branches in place or create and reopen worktrees, reusing an open space when available.

- Default space titles follow the selected directory and branch until edited.
